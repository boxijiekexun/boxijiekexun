数据库课程设计，使用 **Go / Gin、MySQL、Vue 3** 实现学生下单、商家履约、管理员管理的业务流程。

- 后端使用事务处理下单，按数据库价格计算金额，并通过条件更新避免库存超卖。
- 实现 JWT 鉴权、角色权限、订单状态流转、数据库连接池、SQL 超时、限流和短时缓存。
- 配有数据库设计、接口流程与运行说明；测试和部署方式仍在完善。
